# Health Buddy Connection Test
This is a read-only Android Health Connect test. It requests permission for steps, sleep, heart-rate records, and weight. It shows what it found or why a read failed. No network permission, no automatic uploads, and no changes to health data.

Use the GitHub Actions artifact named health-buddy-test-apk, extract the .apk, and install it on Android. Open Health Buddy Test, tap TEST CONNECTION, and approve permission requests. Data remains on phone.
